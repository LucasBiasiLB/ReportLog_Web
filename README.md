# ReportLog_Web

![logo](./assets/image/logo.png)

## Descrição

O ReportLog_Web é uma aplicação web que permite aos usuários criar e gerenciar sugestões sobre o jogo ReportLog. Os usuários podem criar sugestões, curtir-las e ver as mais curtidas. Os administradores podem tudo que os usuários fazem, mais criar ou deletar updates e sugestões.

## Funcionalidades

- **Sugestões**: Os usuários podem criar sugestões para o jogo ReportLog.
- **Updates**: Os usuários podem ver updates sobre o jogo ReportLog.
- **Curtidas**: Os usuários podem curtir sugestões de outros usuários.
- **Sugestões mais curtidas**: Os usuários podem ver as sugestões mais curtidas.
- **Deleção de updates**: Os administradores podem deletar updates e sugestões já aplicadas no jogo.

## Tecnologias Utilizadas

- **HTML**: Estrutura da página
- **CSS**: Estilização da página
- **JavaScript**: Lógica da aplicação
- **PHP**: Backend da aplicação
- **Firebase/WampServer**: Banco de dados

## Como Executar

1. Clone o repositório dentro do diretório "www"
2. Configure o arquivo `config.local.php`
3. Tenha a pasta `chaveAPI_ReportLog` com as configurações do Firebase (dados sensíveis) fora do diretório "www"
4. Execute o servidor wampserver

## Como Usar

1. Acesse a página inicial
2. Crie uma conta ou faça login
3. Crie sugestões
4. Curtir sugestões
5. Ver as sugestões mais curtidas
6. Deletar/Criar updates ou sugestões (apenas administradores)
